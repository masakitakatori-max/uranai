# 四柱推命の参照資料

`sources.json` は出生月令と日干に応じて選ぶ139件の資料です。AIの過去回答は含めていません。各項目には出所、原文/注釈/和訳/要約の区別、行番号、本文のSHA-256を保存し、回答で使用した資料を画面から確認できます。

- 窮通宝鑑: ローカルの `穷通宝鉴_和訳.md` から日干・季節・月別の段落を採録。
- 滴天髄: ローカルの `滴天髄_和訳.md` から天干篇と旺衰・体用・通関・寒暖・燥湿・従象・化象・夫妻等を採録。章末要約は「ローカル要約（原文ではない）」と明記。
- 子平真詮: 沈孝瞻本文の「論用神」「論用神成敗救應」から抜粋。各項目のoriginに掲載先URLを記録。徐氏評注とは区別。

本索引は完全な古典全集ではありません。資料の存在とID整合は検証できますが、解釈の正しさの自動保証にはなりません。資料が不足する観点はAIに保留させ、古典中の身分・性差・疾病・夭寿の断定を利用者へ転用しないよう指定しています。

月別資料の該当日干/月、共通理論、二人比較時の夫妻資料を選択します。原局の事実と解釈を混ぜず、出典・命式のIDに戻れる構造で将来の資料追加・専門家校訂を行います。
