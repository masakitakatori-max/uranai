占術ワークスペース — スマホ再定義

現行の Web 版は「全モードの巨大フォームを一画面に並べる」構成でした。モバイルでは 目的 → 起局 → 要点 → 盤 → 記録 の一本道に組み替え、盤面の情報量は段階開示で保持します。和の書物感（明朝・金・墨）はブランド資産として維持しつつ、操作系はiOSネイティブの作法に寄せました。
