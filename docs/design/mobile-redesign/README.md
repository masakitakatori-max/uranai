# Handoff: 占術ワークスペース モバイル UI/UX 再設計（iOS）

## Overview

既存の Web アプリ `masakitakatori-max/uranai`（React 19 + Vite + Capacitor / iOS Bundle ID `jp.co.mozule.uranai`）を、スマートフォン（iOS）向けに再定義したハイファイ設計です。

現行版は「6モード分の巨大な入力フォームと盤面を1画面に並べる」デスクトップ前提の構成でした。本設計では導線を
**目的 → 起局 → 要点 → 盤 → 記録** の一本道に組み替え、盤面の情報密度は段階開示（progressive disclosure）で維持します。

対象画面は9面（オンボーディング / ホーム / 質問入力 / 起局条件シート / 結果サマリ / 盤詳細 / 記録一覧 / 設定 / デザインシステム）。

## About the Design Files

同梱の HTML ファイルは **HTML で作成したデザインリファレンス（プロトタイプ）** です。見た目と意図した挙動を示すものであり、そのまま本番コードとしてコピーするためのものではありません。

実装タスクは、**この HTML デザインを既存コードベースの環境（React 19 + TypeScript + Vite、素の CSS = `src/App.css`）の作法に沿って再現すること**です。既存の `src/components/*.tsx` と `src/lib/*`（占術ロジック）はそのまま活かし、UI レイヤのみを差し替える想定です。占術の算出ロジックには一切手を入れないでください。

- `uranai-mobile-design.dc.html` — 9画面すべてを含むデザインドキュメント（ブラウザで直接開けます）
- `ios-frame.jsx` — iPhone のベゼル/ステータスバーを描くだけの表示用スキャフォールド。**実装には不要**です（実機の SafeArea を使うこと）

## Fidelity

**High-fidelity（ハイファイ）**。配色・タイポグラフィ・余白・角丸・タップ領域まで確定値です。ピクセル単位で再現してください。
ただしアイコンは未確定（現状は漢字1文字のグリフで代用）。下記「Assets」参照。

### Spacing / Shape

- 余白は 8 の倍数（4 は微調整のみ）。画面左右パディング **20px**（オンボーディングのみ 24px）。
- 角丸: **10**（盤セル）/ **11〜12**（小コントロール）/ **14〜16**（ボタン・カード・リスト群）/ **18〜20**（強調カード）/ **28**（ボトムシート上端）/ **999**（chip・pill）

## Interactions & Behavior

- **ナビゲーション**: ホーム →（NOWカード or 目的チップ）→ 03 質問入力 → 04 起局条件シート → 05 結果サマリ → 06 盤詳細。戻るは iOS 標準のスワイプバック + `‹`。
- **04 シート**: 下からスライドイン（0.35s / `cubic-bezier(0.32,0.72,0,1)`）、背面ディムのフェード 0.25s。グラバーの下スワイプで閉じる。
- **セグメント / チップ**: 選択切替は 0.15s の背景色トランジション。ハプティクス（`selection`）を付与。
- **06 盤**: タブ切替はクロスフェード 0.2s（横スワイプでも切替可）。セルタップで用語ポップオーバー（天将・支・五行の短い解説 → 辞典へ）。
- **AI解説**: 実行中はボタンを「生成中…」に置換し無効化（既存 `AiFeedbackPanel` の `isLoading` を踏襲）。エラー時は 05 のボタン直上に `role="alert"` のバナー。
- **境界時刻の警告**: 補正後時刻が時支境界の ±5分以内のとき 04 に表示。結果画面では確度を「要検証」に落とす。
- **ローディング**: 起局は基本クライアント計算で即時。300ms を超える場合のみ盤グリッドをスケルトン表示（セルの背景のみ、テキストなし）。
- **空状態**: 記録が0件のとき「まだ記録がありません」+「いま起局する」ボタン。
- **アクセシビリティ**: Dynamic Type 対応（設定「文字サイズ」）。盤セルは色だけでなくラベル文字でも五行を判別できるようにする。コントラストは本文 4.5:1 以上を確認済み。

## State Management

既存の `App.tsx` が持つ `mode` と各 `*Input` state をそのまま活用しつつ、以下を追加します。

- `route`: `onboarding | home | question | conditions | summary | board | history | settings`（React Router または簡易スタック）
- `hasOnboarded: boolean`（永続化）
- `defaults: { locationId, useTrueSolarTime, nobleChoice, fontMode, textScale, furigana }`（永続化 = Capacitor Preferences / localStorage）
- `draft: { questionText, topic, datetimeMode: 'now' | 'manual', datetime, overrides }`
- `chart`: 既存 `LiurenChart | QimenChart | ...` をそのまま
- `history: SavedReading[]`（`{ id, mode, question, chartInput, chartSnapshot, certainty, createdAt, verdict? }`）を永続化。`verdict` は後追い検証（当たり/外れ/未判定）用の新規フィールド。
- `boardTab`: `天地盤 | 四課 | 三伝 | 関係`
