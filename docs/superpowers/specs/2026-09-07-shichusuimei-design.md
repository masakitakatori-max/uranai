# 四柱推命：用神論と相性論

ユーザー承認済みの方針：課金を後回しにし、占い機能とSDKによるAI解説を実装する。相性は二人の命式、命式内の組み合わせ、大運との関係を含む。

## 完成時の動作

`/shichusuimei/` で生年月日時・UTC時差・大運順逆に使う性別を入力し、日主が明確な四柱・全蔵干・十神・十二運・大運を見る。命式はローカル計算スキルの規約（立春・十二節・23時日替り・真太陽時補正なし・3日1年）を採用。計算は再現可能にする。境界値と近似精度を明示する。

通根の所在と軽重、月令、生扶泄耗克を機械で列挙し、通常格を前提にした旺衰の暫定評価を返す。完全な古典解釈と同一視しない。格局、扶抑、病薬、調候、通関、特殊格、成敗救応を古典資料と照らすAIが総合評価する。

用神の回答は具体的な干支、目的、根拠となる命式の箇所と資料、成立条件、妨げるもの、代替案、未解決点を含む。二人の相性は双方向の働き、補い合う点、ぶつかる点、条件を返し、百分率の相性点は付けない。相手の命式を原局に足して通根を成立させない。大運は出生月令を変えず重ねる。

既存モックの構造を本番コンポーネントへ移す。天干の大きさ・濃さは根の所在を表し、日主は固定で強調。蔵干は地支の中に表示。関係は作用元・作用先・名称を直接示し、意味不明な曲線は使わない。干の自然比喩は季節・根・組み合わせで状態を変え、表示規則と解釈の確定度を区別する。

AIは公式Claude Agent SDKでローカルNode APIから呼ぶ。接続先や認証はサーバー側に置き、ツール実行なし、構造化JSON、ターン/時間/予算の上限を設定。古典の該当節をサーバーで選び入力し、JSONの形・命式ID・出典ID・方向を検証する。入力はサーバーで再計算する。偽の解説へのフォールバックは禁止。

既存の個人履歴APIは使わず、今回のUIの状態に結果を保持する。入力・対象大運・相談の変更で古い解説を失効させる。二重送信を抑え、取消/失敗/未接続を区別する。原価usageは返せる形で保持するが課金しない。実際の決済、共有RAGは今回の対象外。ユーザーの追加指示により、機能確認後のmainマージと公開デプロイを含む。

## 実装と検証の境界

暦の検算、判定規則のテスト、AI構造検証、入力変更・二人比較・エラーの画面テスト、ビルド、ブラウザ、実SDK応答を別々に確認する。古典の全解釈を網羅した、占断の当否が科学的に保証された、という主張はしない。
